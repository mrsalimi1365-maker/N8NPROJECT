## امکانات اصلی
- بوم نقاشی تعاملی با پشتیبانی از ماوس و لمس
- انتخاب رنگ قلم
- تنظیم اندازهٔ قلم
- پاک‌کن
- پاک‌کردن کامل بوم
- بازگشت آخرین تغییر
- ذخیرهٔ نقاشی به‌صورت فایل PNG
- طراحی واکنش‌گرا برای رایانه و موبایل
- رابط کاربری فارسی و راست‌به‌چپ

## ساختار فایل‌ها
- `index.html`: ساختار صفحه، نوار ابزار و بوم نقاشی
- `style.css`: ظاهر، چیدمان واکنش‌گرا و حالت‌های تعاملی
- `script.js`: منطق رسم، لمس، انتخاب ابزار، بازگشت و ذخیرهٔ تصویر
- `package.json`: فرمان اجرای تست
- `test.js`: آزمون‌های داخلی Node.js برای بررسی وجود عناصر اصلی و قابلیت‌های مورد انتظار

## جزئیات پیاده‌سازی
1. ایجاد یک رابط ساده با عنوان برنامه و نوار ابزار.
2. استفاده از `canvas` برای رسم خطوط نرم.
3. پشتیبانی از رویدادهای `pointer` تا ماوس، قلم نوری و لمس با منطق مشترک کار کنند.
4. نگهداری تاریخچهٔ تصویر برای قابلیت بازگشت.
5. استفاده از رنگ پس‌زمینهٔ سفید هنگام خروجی گرفتن PNG.
6. جلوگیری از اسکرول ناخواستهٔ صفحه هنگام نقاشی در موبایل.
7. افزودن برچسب‌ها و کنترل‌های قابل استفاده برای دسترس‌پذیری.
8. اجرای تست با `npm test` برای اطمینان از وجود عنوان، بوم، کنترل رنگ، اندازهٔ قلم و دکمهٔ ذخیره.
